Privacidade

Sintoniza Concursos não coleta, armazena ou compartilha dados pessoais.

Todas as suas preferências, favoritos e configurações ficam salvos apenas no seu navegador (localStorage).

Nenhuma informação é enviada a servidores externos. As buscas são feitas diretamente em fontes públicas (Google News, feeds RSS).

Ao limpar os dados do navegador, todas as informações do app serão perdidas. Use a opção Exportar para fazer backup.
